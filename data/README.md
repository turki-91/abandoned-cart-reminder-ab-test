# البيانات الاصطناعية

ينشئ `python main.py` ملف `data/dataset.csv` ببذرة 2026. يتضمن 31,500 مستخدم اصطناعيًا، وصفًا لكل مستخدم، وتخصيص A/B، ويوم التسجيل، والمتابعة، والشراء، والإيراد، والربح، والإلغاء، والتواصل مع الدعم.

تمثل قيمة الطلب الفارغة المستخدمين الذين لم يشتروا. المقاييس الثنائية والإيراد والربح متاحة لجميع الموزعين. يحتفظ المستودع بالجداول المجمعة والرسم في `outputs/`، ويولّد السكربت ملف الصفوف عند التشغيل.
